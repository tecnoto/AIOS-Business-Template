# Hard Prompts Layer

Reusable instruction templates for common AI sub-tasks.

## What Goes Here

- `summarize_transcript.md` — Video/audio transcript → structured summary
- `write_kb_article.md` — Raw data → knowledge base article
- `create_outreach_email.md` — ICP + context → personalized email
- `rewrite_in_voice.md` — Content → brand voice rewrite
- `create_visual_brief.md` — Concept → image generation prompt

## How to Use

These are fixed instruction templates. The AI uses them as sub-task prompts when executing workflows. They define the "how" for common content operations.

Create templates as you identify repeating patterns in your workflows.
