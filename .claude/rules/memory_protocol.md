## Memory Protocol

- Auto-capture runs via Stop hook — don't duplicate manually
- Before repeating past work or making architectural decisions, search memory first
- Use the `memory` skill for on-demand operations (search, add, sync, list, delete)
- Don't load all memories into every session — search when relevant
- Update `memory/MEMORY.md` only for truly persistent facts that should always be loaded
- Daily logs go in `memory/logs/YYYY-MM-DD.md`
- Tag memories with types: fact, preference, event, insight, task, relationship
