# Client Onboarding

> Fill in these templates to capture everything needed to build a client's AI Operating System.
> Work through them in order — each builds on the previous.

## Process

1. **Discovery Interview** — Understand the business, team, and pain points
2. **Department Map** — Map org structure to agent hierarchy
3. **Workflow Inventory** — Document current workflows and automation opportunities
4. **Brand Profile** — Capture voice, identity, and customer profile
5. **Technical Requirements** — Inventory existing tools and integration needs
6. **Scope of Work** — Define what to build, timeline, and pricing
7. **Compiled Business KB** — AI auto-generates a unified knowledge base from 01-06

## Scaling by Business Type

- **Solo/Small**: Focus on 01, 03, 04, 06. Skip department mapping.
- **Mid-Market**: All documents. 2-5 departments.
- **Enterprise**: All documents + sub-team detail. Change management section critical.

## After Onboarding

The completed documents feed directly into the AI OS:
- Interview answers → `memory/MEMORY.md` (persistent facts)
- Brand profile → `context/brand_profile.md`
- Workflow inventory → Skills to build
- Technical requirements → MCP connectors + integrations
- Department map → `departments/` sub-agent structure
